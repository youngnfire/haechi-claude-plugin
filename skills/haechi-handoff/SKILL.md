# 해치 인계 문서 쓰기

사용자가 지금 하던 일을 해치에게 넘기려 한다. 해치는 이 작업 폴더의 `.haechi/handoff.md`를 읽고 이어서 일한다. 해치는 이 대화를 볼 수 없으니, 처음 보는 사람이 이어 받을 수 있게 쓴다.

## 지킬 것

1. **쓰는 파일은 두 개뿐이다.**
   - `.haechi/handoff.md` — 지금 작업 폴더(현재 디렉터리) 아래. 이미 있으면 덮어쓴다. 최신 하나만 둔다.
   - `.haechi/.gitignore` — 없을 때만 만든다. 내용은 `*` 한 줄이다. 인계 문서가 사용자의 git 저장소에 커밋되지 않게 한다.

   이 두 파일 말고는 아무것도 쓰거나 고치거나 지우지 않는다. 명령(셸, 빌드, 시험, git)도 실행하지 않는다. 필요한 사실은 이미 대화에 있는 것과 파일 읽기로 확인한 것만 쓴다.
2. **비밀은 값을 쓰지 않는다.** 이름만 쓴다(예: 「`STRIPE_KEY` 환경 변수 필요」). API 키, 토큰, 비밀번호, 쿠키, 개인 키, 접속 문자열 안의 비밀번호도 같다. 대화나 파일에 값이 보였어도 옮기지 않는다.
3. **근거를 나눈다.** 각 절에서 대화에서 들은 것은 「(대화)」, 폴더 파일을 읽어 확인한 것은 「(파일 확인)」으로 표시한다. 확인하지 못한 것은 「확인하지 못한 것」 절에 둔다. 추측을 사실처럼 쓰지 않는다.
4. **크기는 20KB 이하.** 긴 출력이나 코드를 통째로 옮기지 않는다. 파일은 경로로, 명령은 한 줄로 적는다.

## 꼴

아래 꼴을 그대로 쓴다. 머리말 키와 절 제목, 절 순서를 바꾸지 않는다. 쓸 것이 없는 절에는 「없음」이라고 적는다.

이 스킬을 불렀을 때 Claude Code가 채운 값:

- 이 컴퓨터 시계: !`date +%Y-%m-%dT%H:%M:%S%z`
- 이 대화 ID: ${CLAUDE_SESSION_ID}

```markdown
---
haechi_handoff: 1
agent: claude-code
written_at: <지금 시각, 시간대를 붙인 ISO 8601. 예: 2026-01-31T14:30:00+09:00>
folder: <작업 폴더 절대 경로>
session: <이 Claude 대화 ID, 모르면 unknown>
---

## 목표
## 끝난 것
## 하던 것과 멈춘 자리
## 다음 할 일
## 관련 파일
## 정한 것과 이유
## 돌리던 명령
## 확인하지 못한 것
```

- `haechi_handoff`는 꼴의 판이다. 지금은 `1`이다.
- `written_at`은 위 「이 컴퓨터 시계」 값이다. 끝의 시간대 `+0900`은 `+09:00`처럼 쌍점을 넣어 쓴다. 그 값이 시각이 아니면(비었거나 명령 글자가 그대로 보이면) 아는 날짜에 `T00:00:00`과 아는 시간대를 붙이고, 시각을 모른다는 것을 「확인하지 못한 것」에 적는다.
- `folder`는 지금 작업 폴더의 절대 경로다.
- `session`은 위 「이 대화 ID」 값이다. 그 값이 ID가 아니면(비었거나 `${` 로 시작하면) `unknown`이라고 쓴다. 폴더 경로나 파일 이름에서 ID를 짐작하지 않는다.

절마다 쓸 것:

- **목표** — 사용자가 이루려는 것. 한두 문장.
- **끝난 것** — 이미 끝낸 일. 커밋이나 파일이 있으면 함께 적는다.
- **하던 것과 멈춘 자리** — 지금 손대던 일과 정확히 어디서 멈췄는지. 막힌 이유가 있으면 적는다.
- **다음 할 일** — 이어 받는 쪽이 바로 할 일을 순서대로.
- **관련 파일** — 작업 폴더 기준 경로와 한 줄 설명.
- **정한 것과 이유** — 대화에서 정한 방향과 그 이유. 버린 선택지도 이유와 함께.
- **돌리던 명령** — 빌드·시험·실행에 쓰던 명령. 비밀이 든 인자는 이름으로 바꾼다.
- **확인하지 못한 것** — 추측, 못 돌려 본 것, 대화가 길어 앞부분이 빠졌을 수 있는 것.

## 끝나면

사용자에게 아래 두 줄만 알린다. `<경로>`는 쓴 인계 문서의 절대 경로다.

```
인계 문서를 썼습니다: <경로>
해치 앱에서 이 폴더가 작업 위치인 대화를 열고 「로컬 작업 가져오기」를 하세요.
```
